# 음악 분리 결과: 현재 음악 probe의 분리 신호 적용은 채택하지 않음

## 판단

현재 고정 음악 probe에 분리된 음악을 입력하는 방식을 제출 후보로 채택하지 않는다. 해당 probe의 File EER는 평가한 세 조건에서 개선되지 않았고, 두 조건에서는 악화됐다. 음량 보정으로도 원본 대비 이점이 확인되지 않았다. 이는 현재 판별기·개발 입력의 결과이며 HTDemucs나 모든 성분별 접근법이 실패한다는 결론이 아니다.

기존 제출 코드와 가중치는 보존했다. 재학습·추가 튜닝·DACON 제출은 수행하지 않았다.

## 고정 음악 probe 비교

수치는 File EER이며 낮을수록 좋다. 원본 / 분리 음악 / 분리 후 음량 보정 순서다.

| 항목 | 수치 | 출처 URL/로컬 파일 | 기준연도 | 비고 |
|---|---|---|---|---|
| 음악 단독 | 25% / 62.5% / 50% | [audit.json](../data/experiments/separation-20260916/audit.json) | 2026 | 16개, 원본이 가장 좋음 |
| 실제 음성이 작은 혼합 | 50% / 62.5% / 62.5% | 동일 파일 | 2026 | 16개, -6 dB |
| 실제 음성이 큰 혼합 | 37.5% / 37.5% / 37.5% | 동일 파일 | 2026 | 16개, +6 dB, EER 개선 없음 |

DF-Arena 원래 점수는 +6 dB에서 File EER가 50%에서 37.5%로 줄었지만 AUC는 0.578125에서 0.484375로 떨어졌다. 따라서 모든 판별기의 모든 수치가 악화됐다는 주장은 하지 않는다. 고정 음악 probe의 +6 dB AUC는 소폭 증가했지만 대회가 사용하는 EER 개선은 없었다.

## 대조 입력에서 드러난 한계

실제 음성 단독 8개를 강제로 분리한 잔여 음악 신호에서 probe 점수 평균은 0.9962725365913869였으며, 8개 모두 0.5 이상이었다. 음악 자료로 학습한 판별기가 이런 잔여 신호를 제대로 처리하지 못한다는 경고다. 잔여 신호 점수를 보정된 실제 확률로 해석하지 않는다.

다만 이 8개는 기존 PANNs 게이트에서 모두 분리를 건너뛰는 입력이었다. **실제 제출 파이프라인에서 8개 모두 오탐했다는 뜻은 아니다.** 분리 강제 실험과 실제 게이트 동작을 구분한다.

생성 음성이 있는 혼합 및 음성 단독 입력 32개는 분리 음악 점수의 File EER 비교에서 제외했다. 음악 성분 정답을 임의로 만들지 않았으며, 이번 지표는 Music EER·Voice EER·전체 대회 Score가 아니다.

## 다음 방향

같은 소량 개발 자료에서 혼합 비율·분리·C를 계속 바꾸는 실험은 중단한다. 현재까지는 음악 단독 개발 자료의 이점이 다른 입력 조건에서 안정적으로 유지되지 않았다. 음악 판별기의 원본·생성기 다양성과 미사용 검증 자료를 먼저 보강하는 방향으로 전환한다. 새 후보와 기존 모델을 같은 자료에서 비교하며, 기존 모델도 후보 선택 기준에 포함한다.

이후 새 자료에서 개선을 확인한 후보에 대해서만 전체 추론·게이트·시간·오프라인 검증을 진행한다. 현재 분리 결과를 이유로 새 제출 파일을 만들거나 대회 점수 향상을 예상하지 않는다.
