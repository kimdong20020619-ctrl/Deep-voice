# 고정 50:50 결합 진단 — 2026-09-20

## 결론

SONICS와 DF-Arena 확률을 절반씩 평균하는 결합은 제출 후보로 채택하지 않는다. 생성기·길이·압축의 20조건 중 기존 DF-Arena보다 EER와 AUC가 모두 개선된 조건은 6개지만, EER가 악화된 조건은 10개다. 일부 조건에서 두 모델이 서로 보완되더라도 일괄 결합의 안정적 개선으로 이어지지 않았다.

이번 결과는 **모든 앙상블이 불가능하다는 증명은 아니다.** 다만 현재 작은 개발 자료에서 가중치를 계속 탐색해 최고점을 고르는 방향은 과적합 위험 때문에 진행하지 않았다. 모델·제출 파일은 변경하지 않았다.

## 방법과 검증

- 분석 전에 규칙을 `0.5 * SONICS + 0.5 * DF-Arena` 하나로 고정했다. 임계값·가중치 탐색 및 학습 없음.
- [생성기 통제 실험](35_generator-result-20260919.md)의 감사된 ZIP과 [SONICS 대조군 실험](32_sonics-result-20260919.md)의 감사된 ZIP을 사용하고 두 파일 SHA-256을 확인했다.
- 실행: `python -X utf8 -B scripts/analyze_fixed_fusion.py`
- 산출물: [analysis.json](../data/experiments/fixed-fusion-20260920/analysis.json)
- 모든 입력 점수의 유한성·범위·평가 모집단을 확인하고, 공식 EER 구현으로 재계산했다.
- 정답을 완벽히 순위화하는 예제와 두 모델의 점수가 반대로 상쇄돼 동률이 되는 예제로 평균 계산 및 순위 집계를 확인했다. 두 검사 통과.
- GPU 재추론은 하지 않았다. 기존 대조군의 DF-Arena 점수는 이전 실행 결과를 참조한다. MP3 대조군의 DF 점수가 없는 기존 SONICS 실험에는 원본 점수를 대신 붙여 비교하지 않았다.

## 대표 결과

EER은 낮을수록 좋다. 모든 수치는 로컬 개발 실험이며 대회 Score가 아니다.

20조건에서 AUC 악화는 4개다. EER와 AUC는 서로 다른 순위 특성을 요약하므로 AUC 개선만으로 대회 EER 개선을 주장하지 않는다. 6개 개선, 10개 EER 악화, 4개 AUC 악화는 상호 배타적인 세 범주가 아니며 합산하면 안 된다.

## 오류 보완의 해석

각 비교 집단의 REAL–FAKE 조합에서 두 모델이 모두 FAKE를 더 높게 순위화하는 경우, SONICS만 맞는 경우, DF-Arena만 맞는 경우, 둘 다 엄격히 맞지 않는 경우를 저장했다. 정답 라벨은 사후 분석에만 사용하며 예측 점수 생성에는 사용하지 않는다.

서로 반대되는 오류가 있어도 점수 척도와 확신 정도가 달라 평균이 둘의 장점만 취하지는 않는다. 이 설명은 관측과 양립하는 해석이지 확정된 인과 원인은 아니다. 같은 샘플이 여러 REAL–FAKE 조합에 재사용되므로 순위 조합 수를 독립 표본 수로 해석하지 않는다. 과거 train/development/holdout 모두 이미 사용한 자료이며 새 잠금 검증셋이 아니다.

## 다음 우선순위

현재 SONICS 재학습·가중치 스윕·일괄 교체는 보류한다. 추가 연구를 이어가려면 먼저 **별도 원본의 확인집단과 실제 성분별 평가가 가능한 라벨**을 마련해야 한다. 파일 점수 실험을 대회 음악 성분 점수로 곧바로 옮기는 것도 피한다. 과거 최고점 제출본과 현재 코드의 정확한 연결 및 전체 파이프라인 재현은 여전히 별도 미완료 사항이다.

현재 사용자가 추가 Colab을 실행할 필요는 없다. 이번에 새로운 GPU 노트북이나 제출 ZIP은 만들지 않았다. 다음 작업은 단순 결합을 더 조정하는 것이 아니라, 위 검증 공백 중 실행 가능한 범위를 먼저 확정하는 것이다.
