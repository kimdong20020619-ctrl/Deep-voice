## 출처와 사용 조건

WaveFake는 CC BY-SA 4.0이며 제공 LICENSE를 함께 넣었다. LJSpeech는 공식 페이지에서 Public Domain 배포와 단일 화자 구성을 다시 확인했다. FakeMusicCaps 페이지는 이번 웹 조회에서 시간 초과가 났다. 해당 라이선스 CC BY-NC 4.0은 이전에 저장한 `data/raw/fakemusiccaps-audit-20260911-v2/manifest.json`의 기록에 의존한다. 이번에 최신 원문 재확인 성공이라고 보고하지 않는다.

서로 다른 라이선스의 음원을 섞지 않고 개별 파일 모음으로 보관했다. 원본·변경 사항·사용 조건은 ATTRIBUTION.txt와 manifest에 기록했다. 이 ZIP 전체에 하나의 라이선스를 덮어씌우지 않는다.

## 다음 단계와 채택 기준

사용자는 C01~C10을 듣고 각 파일에 대해 **음악만 / 목소리만 / 둘 다 / 잘 모르겠음**으로 답한다. 이전 9개를 다시 들을 필요는 없고 CSV 작성도 필요 없다. 불확실한 항목은 임의로 채우지 않는다.
