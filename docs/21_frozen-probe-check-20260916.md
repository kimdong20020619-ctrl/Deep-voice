# 고정 가중치의 음량·실제 추론 경로 검사 — 2026-09-16

## 판단과 목적

첫 프로브 학습은 작은 확인셋에서 개선됐지만, 학습 음량 정규화와 제출 입력의 차이 및 전체 추론 경로 적용은 확인되지 않았다. 다음 단계는 새 가중치 학습보다 이 적용 위험을 먼저 확인하는 것이다. 이 문서는 내부 실험 기록이며 대회 제출 보고서 본문이 아니다.

선택 가중치를 그대로 고정한다. 이전 확인셋과 학습셋은 사용하지 않고 개발 원본 16개를 네 조건으로 변환한다. **64개 입력이지만 독립 원본은 16개**다. 개발 데이터 진단이므로 독립 일반화 평가, 대회 총점, 새로운 확인셋 평가라고 부르지 않는다.

## 입력 조건과 비교 의미

1. `reference`: 학습 실험 번들의 PCM16 음원 그대로. 기존 전처리를 기준으로 삼는다.
2. `float_reference`: reference를 정확히 같은 파형의 float WAV로 저장. 파일 저장 형식 차이를 대조한다.
3. `quiet`: reference 진폭을 0.1배로 줄여 float WAV로 저장. float_reference와 비교하면 파일 형식은 동일하다.
4. `original_level`: 원본 중앙 8초를 원래 음량으로 유지한 float WAV. 1을 넘는 float 진폭도 조용히 잘라내지 않는다.

모든 입력은 mono 16kHz, 8초다. 원본 출처와 라이선스는 이전 데이터 번들의 내용을 보존하며 새 변경 내역도 기록한다. NoDerivatives로 제외했던 항목은 들어 있지 않다.

## 실행 내용

각 입력에 기존 PANNs·Demucs·DF-Arena 파이프라인을 프로브 없이 한 번, 고정 FILE 프로브를 연결해 한 번 실행한다. 같은 원본 오디오를 DF-Arena로 직접 처리한 특징에서도 프로브 점수를 계산한다.

- 전체 경로 FILE 출력과 단독 특징 기반 FILE 출력의 수치 일치를 검사한다.
- FILE 이외 네 확률이 프로브 연결 전후 달라지지 않는지 검사한다.
- 수치 대조는 atol/rtol 각각 1e-5이며 초과하면 결과 행·로그를 남기고 중단한다. 실제 GPU의 비결정성이나 경로 차이 때문에 실패한다면 원인을 분석해야 하며 자동으로 허용 오차를 늘리지 않는다.
- 설정·C·가중치·임계값을 학습하거나 탐색하지 않는다. 조건별 File EER/AUC만 기록한다.
- 원본 해시·크롭 해시·가중치 해시를 보존하며 마지막에도 가중치가 변하지 않았는지 검사한다.

전체 경로 반복 실행과 별도 특징 계산을 하므로 이전 특징 추출보다 비용이 크다. 검사 시간은 제출 시간이나 1,200개 추론 시간으로 환산하지 않는다.

## 로컬 검증 완료 범위

테스트 3개 통과: 실제 64개 입력의 형식·유한값·해시·조건 간 파형 관계, 모의 추론의 경로 일치 및 점수 계산, 경로 불일치 시 중단과 요약 미생성. 모의 추론 점수는 실제 모델 성능이 아니다.

추가 확인: ZIP CRC, 모든 코드 셀 문법, 노트북의 예상 번들 해시, 번들 실행 코드와 로컬 코드 일치, 가중치가 이전 결과와 동일함을 확인했다. 기존 확인셋 행이 없고 모든 입력의 split은 development다.

실제 GPU 경로 일치와 조건별 성능은 아직 미검증이다. 오류가 없다고 보장하지 않는다. 이번 검사가 통과해도 실제 음성·가창·혼합·전화·압축·긴 파일의 회귀와 전체 Score는 별도 데이터로 검증해야 한다. 개발 진단 결과를 확인한 뒤 기존 확인셋으로 반복 튜닝하지 않는다.
