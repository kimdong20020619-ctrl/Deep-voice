# 고정 판별기의 음악 분리 전후 비교

## 목적

혼합 학습 후에도 실제 음성+생성 음악의 개발 File EER가 개선되지 않은 결과를 바탕으로, 분리된 음악 신호에 기존 음악 학습 FILE probe를 적용했을 때 변화가 있는지 확인한다. 재학습·C 탐색·임계값 튜닝·새 모델 자동 선택은 하지 않는다. 제출 코드는 수정하지 않는다.

## 사전 고정한 비교

`mixed_probe_bundle.zip`의 개발 입력 80개를 바이트 그대로 재사용한다. 각 입력에서 기존 DF-Arena 점수와 기존 음악 전용 probe 점수를 아래 세 경로로 얻는다.

1. 원본 입력.
2. HTDemucs가 반환한 음악 신호. 음량 및 길이를 임의로 수정하지 않는다.
3. 분리 음악을 RMS 0.05로 맞추되 피크 0.95 제한을 적용한 신호. 제출 코드의 무음 기준보다 작은 신호는 증폭하지 않는다.

원본/분리 음악의 음량, 음량 보정 배율, 길이, 분리 신호 합과 원본의 차이를 저장한다. 분리 음악 WAV와 각 경로 특징도 반환한다. 음량 보정 효과를 분리 효과와 혼동하지 않기 위한 비교이며, 음량 보정이 반드시 유익하다고 전제하지 않는다.

진단 목적상 80개 전부에 분리를 강제한다. PANNs 존재 점수와 기존 제출 코드의 게이트가 분리를 실행했을지 여부를 함께 기록한다. 따라서 이 실험 자체는 전체 제출 파이프라인의 재현이나 실행 시간 검증이 아니다. 이전 Colab 실행의 원본 점수와 이번 원본 점수 차이도 기록하여 실행 환경에 따른 차이를 확인한다.

## 평가 대상 구분

- 음악 단독 16개, 실제 음성+음악의 -6 dB 혼합 16개, +6 dB 혼합 16개: 총 48개를 대상으로 경로별 **File EER/AUC**를 계산한다.
- 음성 단독 16개와 생성 음성+실제 음악 혼합 16개: 별도의 대조 입력 32개로 저장한다. 음악 신호 점수를 파일 전체 정답에 대입한 EER를 보고하지 않는다.
- 음악 원본에 보컬이 있을 수 있으므로 성분별 진위를 추측하지 않는다. 이번 지표는 공식 Music EER가 아니며 Voice EER와 대회 전체 Score도 계산하지 않는다.
- 고정 probe는 음악 자료에서 학습한 FILE 판별기다. 분리 음악 성분용 판별기로 검증됐다는 뜻이 아니다.
- 같은 개발 음악과 파생 혼합을 재사용한다. 80개를 신규 독립 자료라고 해석하지 않는다. 개선되더라도 미사용 자료 검증이 필요하다.
