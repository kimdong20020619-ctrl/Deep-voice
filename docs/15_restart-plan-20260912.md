## 결론과 범위

기준 제출물과 재사용 가능한 추론 코드는 유지하고, 검증 데이터·실험 기록·후보 선정 체계를 다시 구축한다. 전체 모델을 무조건 새로 학습하는 것은 현재 데이터·GPU 실측이 없는 상태에서 선택할 근거가 없다. 새 백본이나 미세조정은 작은 실험에서 필요성이 드러날 때 확대한다.

사용자가 기획 단계부터 재평가·재구축을 허용했다. 이 권한에 따라 로컬 분석 도구와 운영 문서를 갱신한다. 기존 ZIP은 덮어쓰지 않는다. 제출과 최종 제출물 선택은 사용자 계정에서 진행하며, 매일 자동 실행되는 작업을 설정한 상태는 아니다.

## 두 작업을 함께 진행한다

### 빠른 경로: 기존 모델의 정확한 재현과 제한된 후보 비교

1. 기존 보존 ZIP 코드와 현재 개발 코드 차이를 명시한다. 기준선 설정만 맞추고 같은 코드라고 간주하지 않는다.
2. GPU에서 공식 더미로 설치·로딩·출력 구조를 확인하고, 공개 실음원으로 분리·직접 추론 경로를 확인한다. 더미 실행은 성능 평가가 아니다.
3. 재현한 같은 코드에서 한 변경만 적용한다. 첫 후보군은 음악 경로의 원본/반주 입력, FILE 경로의 세그먼트 집계, 스테레오 보존이다. 기존 제출과 의미가 같은 반복 실험은 제외한다.
4. 학습하지 않는 후보도 실제 추론 완주·유한값·ID·오프라인 동작·시간/메모리를 확인한다. 음성·음악 라벨이 갖춰진 검증셋이 있으면 총점까지 비교한다.
5. 검증셋이 충분하지 않으면 성능 미검증임을 명시하고 근거 있는 한 가지 가설의 후보만 제출 대상으로 둔다. 상수 출력으로 점수를 역산하는 제출을 기본 운영으로 삼지 않는다.

### 학습 경로: 작은 데이터로 음악 판별 실험

1. 실제 음악 원본을 확보하고 LICENSE·보컬 주석·파일을 대조한다. 미러 메타데이터 수집이 오래 걸리면 다른 출처로 전환한다.
2. FakeMusicCaps와 실제 음악의 길이·인코딩을 맞춘다. 가짜만 반복해서 길이를 늘리는 합성은 사용하지 않는다.
3. 원곡/설명 ID·연주자·생성기별로 분리한 학습/개발/최종 확인 목록을 고정한다. 분할 뒤 크롭한다.
4. 기존 임베딩의 작은 선형 판별기로 출발한다. 음악 단독 데이터의 Music EER은 진단 지표이며 공식 총점으로 포장하지 않는다.
5. 음악 개선이 보이면 음성/음악 혼합셋에서 FILE·VOICE 회귀를 검사한다. 단순 후보가 실패하면 오류 유형을 확인한 뒤 미세조정·새 백본을 검토한다.

## 무료 GPU 실행 준비 완료 범위

사용자가 Kaggle 또는 Colab 무료 GPU를 사용할 수 있다고 확인했다. 기존 Colab 검증 노트북을 먼저 사용한다. GPU 종류·가용 시간은 실제 배정 결과에 따른다.

- `scripts/make_verify_notebook.py`: direct 출력에 fusion 식을 강제하던 검사를 수정. GPU 미배정·설치 실패·기본 추론 실패 시 명시적으로 중단. 설치/기본 추론 전체 로그 저장.
- `notebooks/colab_verify.ipynb`: 생성기를 통해 재생성. 무료 GPU와 평가 서버의 차이, 성능 평가가 아님을 표시.
- `verify_bundle.zip`: 현재 개발 코드와 최근 검증 라이브러리로 갱신. 대용량 가중치는 기존 노트북 경로로 받고 제공 해시와 대조한다.
- 이 번들은 보존된 기존 제출 ZIP과 동일한 코드라는 뜻이 아니다. 먼저 개발 코드 실행을 확인한다.

실행 순서:

1. https://colab.research.google.com/ 에서 파일 → 노트북 업로드로 `notebooks/colab_verify.ipynb`를 연다.
2. 런타임 → 런타임 유형 변경에서 무료로 배정 가능한 GPU를 선택한다. 유료 업그레이드는 필요 조건이 아니다.
3. 위에서부터 셀을 실행하고 업로드 창에 프로젝트 루트의 `verify_bundle.zip`을 올린다. 대회용 `submit.zip`과 혼동하지 않는다.
4. 다운로드된 모델 해시가 일치해야 다음 단계로 진행한다. 오류가 나면 이후 셀을 억지로 실행하지 않는다.
5. 기본 추론 returncode 0, 형식 검사 통과, 포맷 검사와 시간 측정 출력을 확인한다. 더미 기반 점수는 정확도 근거로 쓰지 않는다.
6. 파일 → 다운로드 → `.ipynb 다운로드`로 출력이 남은 노트북을 저장한다. 오류 시 `/content/install.log`, `/content/inference.log` 중 생성된 로그도 저장한다. 런타임 종료 전에 보존한다.

로컬 확인은 노트북 셀 문법·번들 일치·ZIP CRC·기존 검증 가드까지이며 실제 Colab 실행은 아직 미실시다.
