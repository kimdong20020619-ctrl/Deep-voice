# 음성·음악 혼합 학습 실험

## 결정과 목적

음악 단독으로 학습한 FILE probe가 음성이 큰 혼합에서 악화된 결과(`24_speech-mix-result-20260916.md`)를 반영한다. 새 실험은 실제/생성 음성과 음악, 혼합 입력을 함께 사용해 작은 FILE 판별기를 학습한다. 기존 제출 코드와 가중치는 교체하지 않는다. 독립 홀드아웃 평가와 대회 제출 준비가 완료된 실험으로 해석하지 않는다.

|---|---|---|---|---|

| 외부 자료 사용 기준 | 공개 접근 및 최소 비영리 사용 허용, 출처 명시 | https://dacon.io/competitions/official/236749/overview/rules | 2026 확인 | 비공개 평가 자료 학습 금지 |

공식 LJSpeech 배포 아카이브에서 길이 8.1초 이상인 24개 원본을 확보하고, ID 해시 순서로 학습 문장 16개와 개발 문장 8개를 고정한다. 학습 합성기는 HiFi-GAN·MelGAN, 개발 합성기는 WaveGlow다. 동일 문장의 실제/생성본은 반드시 같은 분할에 둔다. 기준 화자는 양쪽이 동일하므로 화자 독립 성능은 측정하지 못한다. 기초 모델의 사전학습 중복도 미확인이다.

음성 수집에서 이름 접미사 차이를 확인해 수정했으며, DNS 오류 및 짧은 HTTP Range 응답이 발생했다. 파일 보존·제한된 재시도·정확한 바이트 위치 이어받기와 ZIP CRC 검증을 적용했다. 전체 대용량 원본 아카이브의 체크섬 검증을 했다고 주장하지 않는다. 개별 원본 해시와 출처는 `data/raw/paired-speech-20260916/manifest.json`에 남긴다.

## 혼합과 분할

기존 음악 학습·개발 분할을 유지하고, 기존 음악 홀드아웃 16개는 제외한다. 원본 음성은 16 kHz로 resample_poly 변환 후 중앙 8초를 사용한다. 모든 종류에 동일하게 RMS 0.05 정규화와 피크 0.95 제한을 적용하며 FLOAT WAV로 저장한다. 실제 음성에 실제 또는 생성 음악을 섞고, 생성 음성에는 이용 조건이 명시적인 실제 음악만 섞는다. 음성/음악 비율은 -6 dB와 +6 dB다.

WaveFake 파생 오디오는 CC BY-SA 4.0으로 표시하며 출처·변경 내역을 동봉한다. 이 파생 혼합에는 MUSAN 원장에 CC BY 4.0 또는 CC BY-SA 4.0이 명시된 음악만 사용한다. FakeMusicCaps의 CC BY-NC 4.0 음원과 WaveFake를 합친 파일은 만들지 않는다. 실제/생성 음악 전체의 이용 조건을 하나로 바꾸지 않으며 파일별 출처 조건을 보존한다. 생성 음성+생성 음악 조합은 이번 실험의 공백으로 남는다.

혼합 파생 파일은 모든 구성 원본의 분할을 따른다. 동일 문장 그룹·음악 그룹·원본 해시·파생 오디오 해시·합성기가 학습과 개발에 겹치면 중단한다. 개발 음악은 이전에 사용한 자료이므로 새 독립 평가 자료가 아니다. 많은 파생 파일을 독립 표본 수로 해석하지 않는다.

## 학습과 판정

- DF-Arena 본체는 고정하고 기존 구현의 FILE 임베딩에 선형 로지스틱 판별기만 적합한다.
- 표준화 통계와 판별기 적합은 학습 자료만 사용한다.
- C 후보는 0.001, 0.01, 0.1로 사전 고정한다. 개발의 음성·음악·두 혼합 조건별 File EER를 같은 비중으로 평균해 선택한다. 동률이면 합친 File EER, 작은 C 순이다.
- 이 평균은 실험 선택 기준이며 대회 Score 공식이 아니다. 전체 5개 지표를 계산한다고 주장하지 않는다.
- 기존 DF-Arena, 음악 전용 probe, 새 혼합 probe를 같은 개발 입력에서 비교한다. 원래 제출 코드의 LinearProbe 계산과 학습 코드의 예측 일치도 검사한다.
- 좋은 개발 결과가 나오더라도 독립 자료 및 전체 추론 경로 검증 전에는 제출용으로 채택하지 않는다. 한국어·새 화자·새 생성기·여러 길이·전화/압축 조건은 여전히 검증 공백이다.

## 검증 상태

`python -X utf8 -B scripts/selftest_mixed_probe.py`: 3개 검사 통과, 건너뛴 검사 없음. 학습 흐름은 실제 sklearn과 모의 GPU 임베딩으로 검사했다. 이는 GPU 모델 실행 검증이 아니다. 최종 번들 CRC·중복 파일명·WAV 해시/형식/길이/유한 값/피크·작업 코드 일치·노트북 문법·번들 SHA를 확인했다. 실제 GPU 실행과 성능은 사용자 Colab 결과 수신 전 미검증이다.

최종 입력은 348개(학습 268개, 개발 80개)이며 원본은 음악 68개와 음성 64개다. 개발 자료는 모델 선택에 사용하므로 독립 평가 점수로 보고하지 않는다. 생성 음성과 섞는 실제 음악은 허용 목록에 해당한 학습 4곡·개발 2곡으로 제한되어 음악 다양성도 부족하다.
