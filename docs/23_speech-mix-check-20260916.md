# 실제 음성·음악 혼합 회귀 검사

## 목적과 범위

기존 FILE 판별기 가중치를 고정하고, 실제 음성 추가 시 기존 추론 대비 오탐과 음악 혼합 파일 판별의 변화를 확인한다. 재학습이나 DACON 제출은 수행하지 않는다.

- 실제 음성: LibriSpeech dev-clean의 서로 다른 화자 8명, 각 중앙 8초.
- 음악: 기존 file-probe 개발 세트 16개(실제 8개, 생성 8개). 홀드아웃은 사용하지 않는다.
- 입력: 실제 음성 8개, 음악 대조 16개, 혼합 32개, 합계 56개. 서로 독립적인 신규 원본 56개가 아니다.
- 실제/생성 음악에 같은 순서로 같은 화자를 연결한다. 두 혼합 조건은 음성 RMS가 음악 대비 -6 dB 또는 +6 dB다.
- 각 원본 RMS를 0.05로 맞춘 뒤 혼합하고, 두 성분에 같은 축소율을 적용하여 피크를 0.95 이하로 제한한다. FLOAT WAV로 저장한다. 음악 대조군도 같은 RMS 정책을 사용한다.

## 출처와 제한

음성 출처: [OpenSLR LibriSpeech](https://www.openslr.org/12/), 2015, CC BY 4.0. 원본 경로·화자·개별 SHA-256은 `data/raw/real-speech-20260916/manifest.json`에 기록했다. 전체 원격 압축 파일의 체크섬은 검증하지 않았다. 로컬에서는 FLAC 헤더와 파일 해시를 검사했고, 전체 디코딩·샘플 수·유한 값 검사는 Colab에서 수행한다.

음악 출처·라이선스는 기존 번들의 MUSAN/FakeMusicCaps 출처 기록을 동봉했다. 생성 음악의 보컬 존재나 성분별 진위는 추측하지 않는다. 실제 음성과 생성 음악의 혼합은 파일 단위 FAKE=1로만 평가한다.

이 음악은 이미 모델 선택에 쓴 개발 자료다. 새 음성은 영어 8명뿐이며 사전학습 데이터와의 중복은 미확인이다. 생성 음성이 없으므로 Voice EER와 대회 전체 Score를 계산할 수 없다. 실제 음성만 있는 그룹의 EER/AUC는 null로 남기며, 0.5 기준 오탐 비율은 보조 진단이다. 공식 EER 임계값과 동일하다고 해석하지 않는다.
