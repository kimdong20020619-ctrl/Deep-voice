# 01. 학습 데이터 설계

> **2차 평가 「학습데이터 구성 보고서」(HWP)의 원본.** 처음부터 보고서라 생각하고 쓴다.
> 상태: P1 완료 시점의 설계. 실제 데이터 구축은 P2(09-09 ~ 09-13)에 한다.

## 1. 배경

본 대회는 학습 데이터를 제공하지 않는다. 따라서 학습셋 구성 자체가 과제의 일부이며,
**평가 데이터의 성질을 학습 데이터에서 얼마나 정확히 재현하느냐**가 성능을 결정한다.

## 2. 재현해야 할 평가 데이터 성질

| 성질 | 값 | 재현 방법 |
|---|---|---|
| 길이 | 4초 ~ 1분 | 랜덤 절단 |
| 샘플레이트 | 16 kHz | 통일 리샘플 |
| 형식 | MP3 · WAV · FLAC 혼재 | 인코딩→디코딩 왕복 |
| 채널 | 일부 전화채널 | 16k→8k→16k + G.711/AMR/Opus 코덱 왕복 |
| 구성 | 음성 · 음악 · **혼합** | SNR 랜덤 믹싱 |

## 3. 합성 파이프라인 (설계)

```
원본 클립
  ① 길이 4~60초 랜덤 절단
  ② 조합: 음성만 / 음악만 / 혼합 / 무음·잡음만 (SNR 랜덤)
  ③ 채널 시뮬레이션: 전화 대역 제한 + 코덱 왕복
  ④ 포맷 왕복: MP3(VBR) / AAC / FLAC
  ⑤ 노이즈 · 잔향(RIR)
  ⑥ 5개 라벨 자동 부여
```

③④가 핵심이다. ASVspoof류에 학습된 anti-spoofing 모델이 무너지는 지점이 정확히
전화채널과 손실 압축이고, 평가셋에 둘 다 명시돼 있다.

## 4. 소스 데이터셋 — DF-Arena 학습 목록이 전략을 규정한다

베이스라인 모델 DF-Arena 1B 의 학습 데이터(모델 카드 명시):

```
ASVspoof 2019 / 2024 · Codecfake · LibriSeVoc · DFADD
CTRSVDD(가창 음성) · SpoofCeleb · MLAAD · EnvSDD(환경음)
```

**이 목록에 있는 것으로 파인튜닝해도 이득이 적다.** 이미 학습된 분포다.
차별화는 **목록에 없는 것**에서 나와야 한다.

| 우선순위 | 영역 | 근거 |
|---|---|---|
| 1 | **생성 음악 (instrumental)** | 악기·반주가 학습 목록에 없다. 실효 가중치 0.27 |
| 2 | **전화채널 · 손실압축** | 평가셋에 명시. ASVspoof 계열은 이 조건에서 무너진다 |
| 3 | **한국어 TTS** | 학습 목록에 한국어가 없다. 국내 대회다 |

후보와 라이선스 판정은 `03_license-ledger.md` 참조.
**라이선스 확인 전에는 채택하지 않는다.**

## 4-1. 제출 가능한 규모로 설계한다

2차 평가 제출물에 **「학습에 활용한 데이터 파일 일체 포함」** 이 명시돼 있다.
대용량 공개 데이터셋 전체를 끌어다 쓰면 제출 자체가 불가능해진다.

→ **실제 학습에 쓴 서브셋 + 시드 고정 재생성 스크립트** 형태로 간다.
   원본 데이터셋 전체가 아니라, 합성 파이프라인이 같은 결과를 재현할 수 있으면 된다.

## 5. 라벨 부여 규칙 ✅ 확정

대회 명세로 확정됐다.

- AI로 **생성된** 음성·음악 성분 → FAKE(1)
- AI로 생성되지 않은 실제 원천 → REAL(0)
- **음성·음악 중 하나라도 FAKE이면 파일 전체가 FAKE**
- **품질 개선·잡음 제거·음량 조정 등 성분 자체를 새로 생성하지 않는 후처리만 적용된 경우 REAL**
- 보컬은 음성 성분이다. 보컬+반주 노래는 **혼합**이다.

> 마지막 두 항이 합성 설계를 규정한다. **REAL 원본에 강한 후처리를 걸어도 라벨은 REAL로 유지한다.**
> 오히려 그런 샘플을 일부러 넣어야 모델이 "후처리 아티팩트 = FAKE"라는 지름길을 학습하는 것을 막는다.
> 이 지름길은 리더보드에서 바로 무너진다.

채점 범위도 확정됐다 — **Voice EER은 음성이 존재하는 샘플에서만, Music EER은 음악이 존재하는
샘플에서만** 계산된다. 즉 음악 없는 파일의 `MUSIC_FAKE_PROB`은 채점되지 않는다.

## 6. 검증셋 분리

**학습에 쓴 생성기와 겹치지 않는 TTS·음악 생성기**로만 홀드아웃을 구성한다.
이 대회의 실질은 미지의 생성기에 대한 일반화이므로, 같은 생성기로 검증하면 측정 자체가 무의미하다.
