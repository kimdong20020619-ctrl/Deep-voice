# 실제 음성·음악 혼합 결과 검토

## 결정

현재 FILE probe의 전면 적용을 보류한다. 음악 개발 자료에서는 개선됐지만 음성이 큰 혼합 조건에서는 File EER가 악화됐다. 실제 음성만의 오탐이 없다는 사실로 생성 음성 탐지 능력을 보장할 수 없다. 이번 결과를 근거로 제출 ZIP을 교체하지 않았다.

## 재계산 결과

EER는 낮을수록 좋다. 아래 값은 `data/experiments/speech-mix-20260916/audit.json`과 보관한 원본 ZIP의 predictions.csv에서 확인할 수 있다. 외부 리더보드 점수가 아니다.

| 항목 | 수치: 기존 → 후보 | 출처 URL/로컬 파일 | 기준연도 | 비고 |
|---|---|---|---|---|
| 음악 단독 File EER | 0.625 → 0.25 | ../data/experiments/speech-mix-20260916/audit.json | 2026 | 기존 개발 음악 16개 |
| 음성이 작은 혼합 File EER | 0.5 → 0.25 | 동일 파일 | 2026 | 음성/음악 -6 dB, 16개 |
| 음성이 큰 혼합 File EER | 0.375 → 0.5 | 동일 파일 | 2026 | 음성/음악 +6 dB, 16개 |
| 실제 음성 오탐 수, 임계값 0.5 | 0/8 → 0/8 | 동일 파일 | 2026 | 실제 음성만 있어 EER/AUC 계산 불가 |

음성이 큰 혼합에서 후보 AUC는 0.5이며, 전체 16개의 후보 점수가 모두 0.5 미만이었다. 낮은 점수 자체만으로 공식 EER 악화를 설명할 수는 없지만, 이 조건에서 진위 순위 분리도 충분하지 않다. 음악에 맞춘 판별기가 혼합 입력에 일반화하지 못한 징후다. 표본이 작으므로 전체 모집단 성능을 단정하지 않는다.

## 검증 근거

- 결과 ZIP SHA-256: `3c6c07f3de52d68eb995e8ede51aedd02d5ee08bcd499f65564ebb76d7859adf`.
- `python -X utf8 -B scripts/audit_speech_mix_results.py` 성공.
- ZIP CRC, 배포 매니페스트 일치, 입력·예측 ID 56개 및 중복 없음, WAV 해시·길이·유한 값·피크 범위, 예측 범위 확인.
- 입력 대조 음성/음악에서 혼합을 재구성한 최대 절대 차이: 1.1920928955078125e-07. 실수 저장 정밀도 범위에서 혼합 비율과 소스 연결이 일치한다.
- 결과 CSV에서 공식 방식의 File EER, AUC, 0.5 판정 비율, 평균 점수를 재계산하여 제공 요약과 모두 일치함을 확인.
- FILE 외 네 출력은 기준/후보 간 허용 오차 내 일치. 실행 로그에 traceback 없음.
- scipy가 WAV의 비오디오 부가 청크를 건너뛰었다는 경고를 냈으나, 오디오 본문은 읽혔고 위 검증을 통과했다.
- 각 파일에서 두 모델을 비교한 시간 합계 약 173.45초. 모델 로딩 등을 포함한 전체 실행 시간이나 평가 서버 전체 테스트 시간으로 해석하지 않는다.
- 반환 ZIP에 실행 코드와 실제 가중치 사본이 없으므로 실제 실행 가중치를 독립적으로 재해시할 수는 없다. 배포 매니페스트 일치와 완료 로그 및 노트북의 해시 검사에 의존하는 범위를 구분한다.

## 다음 단계

음악 단독 학습의 한계가 드러났으므로 추가 음악 단독 성능 확인을 반복하지 않는다. 우선 실제/생성 음성 및 실제/생성 음악의 조합을 포함하는 학습·검증 구성을 설계하고, 원본 화자·음악 그룹이 서로 섞이지 않도록 분리한다. 이번에 확인한 혼합 입력은 개발 회귀 검사로만 취급하고 새 홀드아웃으로 재사용하지 않는다.

혼합 학습과 분리된 음악 성분 활용을 후속 후보로 검토할 수 있지만, 아직 개선이 검증된 방법은 아니다. 특히 생성 음성 자료와 성분 정답이 없어 전체 Score 개선을 판단할 수 없으며, 후보 선택 전에 이 공백을 먼저 보완해야 한다. 기존 제출본과 고정 가중치는 보존한다.
