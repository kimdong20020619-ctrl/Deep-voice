# SONICS 실패 조건 분석 — 2026-09-19

## 결론

음악 탐지기 교체보다 **검증 데이터의 생성기·길이·혼합 조건을 분리하는 것이 다음 우선 작업**이다. 기존 음악 개발 집단은 48개 파일이지만 가짜 음악 원본은 AudioLDM2의 8개다. 음악 원본 16개에 두 가지 음성 혼합 조건을 추가한 것이므로 독립된 음악 48개로 해석하면 안 된다.

SONICS의 방송 음원 개선은 관측됐지만, 생성기·길이·음악 내용·전처리가 함께 달라 원인을 하나로 확정할 수 없다. 현재 파일별 점수로 임계값이나 융합 가중치를 튜닝하지 않았다. 제출 모델은 유지한다.

## 수행과 재현

- 실행: `python -X utf8 -B scripts/analyze_sonics_failures.py`
- 입력: 보관한 SONICS 결과 ZIP, SHA-256 `53e6db5540cf29d223a0698dbdfca88338704356ee4f37e21e788c7685d25da0`
- 산출물: [failure_analysis.json](../data/experiments/sonics-20260919/failure_analysis.json)
- 전체 입력의 코드·예측 감사는 [32번 기록](32_sonics-result-20260919.md)을 따른다.
- 이번에는 GPU 재실행 없이 기존 로짓·라벨·출처를 연결했다. 첫 실행에서 세부 대조군에 한 클래스만 존재해 지표 계산이 중단됐다. 그 집단은 EER/AUC를 null로 명시하도록 수정한 뒤 정상 완료했다. 단일 클래스 점수를 임의로 채우지 않았다.

## 확인한 사실

아래 수치는 모두 로컬 결과다. EER은 낮을수록 좋다. 점수 평균은 확률 보정 정확성을 뜻하지 않는다.

음악 원본에서 실제 음악 Hi_Rez 2개의 평균 점수는 0.586694이며, AudioLDM2 8개 평균은 0.194866이다. 일부 실제 음악에 높은 점수를 주고 일부 생성 음악에는 낮은 점수를 주는 현상이 있다. 그러나 아티스트별 표본이 너무 적어 아티스트/장르 원인이라고 단정할 수 없다. MUSAN 음악에는 보컬이 있을 수 있으므로 여기서 ‘음악 원본’은 ‘음성 성분이 전혀 없음’을 뜻하지 않는다.

가짜 음성+실제 음악 대조군은 혼합 조건별로 모두 FAKE이므로 해당 소집단만으로 EER/AUC를 계산할 수 없다. SONICS가 낮은 점수를 냈다는 사실을 파일 전체 탐지 실패와 음악 성분 탐지 실패에 똑같이 적용해서는 안 된다. 실제 음악 성분만 보면 REAL이기 때문이다.

## 개선 폭의 불확실성

외부 방송의 REAL/FAKE 쌍을 보존해 1,000회 부트스트랩했다. SONICS-DF-Arena 차이의 탐색적 95% 백분위 구간은 EER `[-0.333333, 0]`, AUC `[0.010330, 0.321181]`이다. EER 개선의 구간은 0에 닿는다. 이미 살펴본 작은 24쌍에 대한 사후 분석이며 확증적 유의성 검정이나 대회 점수 상승의 보장은 아니다. 파생 혼합 파일을 독립 표본으로 부트스트랩하지 않았다.

## 다음 실험 설계의 변경

다음 GPU 실험은 현재 데이터의 점수를 더 맞추는 스윕 대신 다음 조건을 충족하도록 구성한다.

1. FakeMusicCaps의 다른 생성기도 포함한다. 기존 train/development/holdout 기록과 중복 여부를 먼저 대조하고 이미 본 자료는 개발 자료로 표시한다. 기존 holdout을 쓰면 그 시점부터 다시 잠금 검증셋이라 부르지 않는다.
2. 같은 원본의 짧은 구간과 긴 구간을 비교하여 길이 효과를 분리한다. 생성기 비교 시 길이·샘플레이트·음량 처리와 코덱을 맞춘다. 방송 초반 구간에 음악이 없을 수 있어 음악 존재 주석도 확인한다.
3. 음악 원본과 실제 음성 혼합을 구분한다. SONICS는 먼저 음악 존재 집단의 후보로 평가하고, 전체 파일 점수의 일괄 대체는 하지 않는다.
4. 별도 원본 확인집단을 정한 후에만 융합을 검토한다. 라벨을 보고 클래스 방향을 뒤집거나 출처별 예외 규칙을 만들지 않는다.

이 문서 시점에서 **새 GPU 노트북·추가 음원 수집은 아직 준비하지 않았다.** 이번 요청의 실패 조건 분석은 완료했다. 다음 실행을 위해서는 위 조건의 자료 구성과 출처 검증이 먼저 필요하다. 현재 사용자에게 반복 Colab 실행을 요청하지 않는다.
