# 04. 실험 로그

> **일일 제출 3회 제한.** 변경점을 1개씩만 반영하고 결과를 여기 남긴다.
> 한 번에 여러 개를 바꾸면 무엇이 점수를 올렸는지 알 수 없고, 되돌릴 수도 없다.
>
> Public = Private = 전체 테스트 100% (분할 없음) → 리더보드 점수를 그대로 신뢰할 수 있다.

---

## GPU 검증 (2026-09-05, Colab **Tesla T4**)

평가 서버는 L4 다. T4 는 Turing 이라 **bf16 텐서코어가 없어** DF-Arena 가 에뮬레이션으로 돈다.
따라서 아래 시간은 **비관적(안전한 방향)** 이다. L4 에서의 실측은 ⬜ 미확보.

### 기능 검증 — 전부 통과

| 항목 | 결과 | 의미 |
|---|---|---|
| 가중치 SHA-256 | 배포 `SHA256SUMS.txt` 와 3개 전부 일치 | HF 리비전 `fb6ce85` = 대회 배포본 |
| 포맷 내성 | **18/18, 실패 0건** | MP3·FLAC·8kHz 전화채널·스테레오·4초 전부 디코딩 |
| 배치 패치 | **최대 편차 0.000000** | 단일 경로와 완전 동일. 수학적 동등성 실증 |
| bf16 vs fp32 | 편차 0.00157 (허용 0.05) | bf16 사용 가능 |
| `fake_index` | 0 (`label2id["spoof"]`) | 배포본 설정 확인 |
| 융합식 | `max(0.650272×0.999364, 0.060305×0.964855) = 0.649859` | `FILE_FAKE_PROB` 과 일치 |

### 단계별 프로파일링 (18파일 / 오디오 450초, 게이팅 OFF)

| 단계 | 시간 | 비중 | s/오디오초 |
|---|---|---|---|
| `df_voice` | 26.41s | 35.4% | 0.059 |
| `df_music` | 26.40s | 35.4% | 0.059 |
| `demucs` | 20.76s | 27.8% | 0.046 |
| `panns` | 0.86s | 1.2% | 0.002 |
| `decode` | 0.19s | 0.2% | 0.000 |
| **합계** | **74.6s** | | **0.166** |

**시간의 71%가 DF-Arena 다. Demucs 가 아니다.**
`df_voice` 와 `df_music` 이 소수점까지 같다 — 두 스템 길이가 같아 세그먼트 수가 같기 때문이며,
모든 파일에서 1B 모델을 정확히 두 번씩 완전히 돌리고 있다는 뜻이다.

`panns` 가 1.2% 라는 것도 중요하다. 존재 탐지(실효 가중치 0.10, 이미 AUC 0.989)는
**성능도 비용도 이미 최적**이다. 손대지 않는다.

### `demucs_gating` 효과

| | s/오디오초 | 비고 |
|---|---|---|
| OFF | 0.166 | 베이스라인과 동일 구성 |
| ON (시험세트) | **0.087** | 1.92배. 분리 생략 15/18 |

게이팅이 켜지면 **Demucs 와 DF-Arena 호출 하나가 동시에** 사라진다
(빈 스템이 무음 게이트 `RMS < 1e-5` 에 걸려 forward 없이 0.0 반환).

**단, 1.92배는 낙관적이다.** 시험세트는 전부 같은 더미(음악 없음)라 83% 가 생략됐다.
실제 평가셋은 음성/음악/**혼합** 3종이므로 생략 비율이 더 낮다.

비용 모델 (검증됨 — 시험세트 예측 0.077+오버헤드 ≈ 실측 0.087):

```
생략 0.059 · 분리 0.164 s/오디오초
83% 생략(시험세트) -> 0.087   ✅ 실측 일치
67% 생략(3종 균등 가정) -> 0.104   ← 실제 추정치
```

### 1,200 파일 환산 (예산 3,565초 = 60분 − 모델 로드)

| 평균 길이 | 게이팅 OFF | 게이팅 ON (시험세트) | **게이팅 ON (실제 추정)** |
|---|---|---|---|
| 20초 | 66.3분 ❌ | 34.6분 ✅ | **41.6분 ✅** |
| 25초 | 82.9분 ❌ | 43.3분 ✅ | **52.0분 ✅** |
| 30초 | 99.5분 ❌ | 51.9분 ✅ | **62.4분 ⚠️** |
| 32초 (4~60초 균등) | 106분 ❌ | 55.4분 ✅ | **66.6분 ⚠️** |

**근거 있는 여유**: 공식 베이스라인(= 게이팅 OFF 구성)이 리더보드에서 실제로 완주한다.
1위 CPS 0.98932 가 그 증거다. 즉 평가셋 총 오디오 길이는 0.166 s/오디오초로 3,565초 안에
들어가는 규모다 → **평균 18초 이하**. 우리는 거기서 1.9배 여유를 더 확보한 상태다.
